|Git operation|What it does in your own words|
|--|--|
|Check repository status|git status, to check the staged, not staged, commited, not commited items|
|Stage selected changes|git add filename, to stage just the particular change or to stage just a particular file and not to stage everything.|
|Create a commit|Creating a version, we can go back to this version whenever we want|
|View commit history|To check our commits(versions)|
