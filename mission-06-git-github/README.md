|Git operation|What it does in your own words|
|--|--|
|Check repository status|git status, to check the staged, not staged, commited, not commited items|
|Stage selected changes|git add filename, to stage just the particular change or to stage just a particular file and not to stage everything.|
|Create a commit|Creating a version, we can go back to this version whenever we want|
|View commit history|To check our commits(versions)|

# Git Command Glossary
|Git operation|Explaination|
|--|--|
|Initialise repository|git init - to initialise git|
|Check status|git status - to check the staged, not staged, commited, not commited items|
|Stage changes|git add - to stage the changes|
|Commit changes|git commit -m "Your msg" - Create a version with msg of what changed|
|View history|git log - check the versions/commits|
|Create or list branches|git switch - either to create a new branch use -c and normal git switch to switch to another branch|
|Bring latest main branch updates to computer|git pull - fetch and merge the changes in main branch in cloud occured doe to merging of pull request|
