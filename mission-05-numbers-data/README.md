# Task 5.2

- decimal to binary: bin(13) -> '0b1101'
- decimal to binary: hex(10) -> '0b11001'
- binary to decimal: int(0b1010) -> 10
- hexadecimal to decimal: int(0xA) -> 10
- hexadecimal to decimal: int(0x1F) -> 31
- binary to hexadecimal: hex(0b1111) -> '0xF'
