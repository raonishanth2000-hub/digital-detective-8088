# Task 4.2

|Point|Compiler|Interpreter|
|--|--|--|
|When translation / execution happens|Translation happens before execution|Translations happens during execution|
|Typical output|A binary file created|Directly shown, no binary file created|
|One example|C++|Python|
|One advantage|Faster|Easy to debug|

- Compiler translates the entire code into a binary file before execution and that binary file is executed. It is faster than interpreter but difficult to debug.
- Interpreter translates one line at a time and the secind line is translated only when first line is executed completely. It is easy to debug but is slower compared to compiler.

- Commands used - 
    - touch
    - echo
    - chmod
    - python3

- Program execution is possible only when the file has executable permission.
