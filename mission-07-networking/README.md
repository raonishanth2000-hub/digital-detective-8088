# Basic network types:
LAN, MAN, WAN

# Task 7.1
|Concept|Explain it in your own words|Example|
|LAN|A network covering a small area, such as a home, lab or office|Students using same wifi in one building|
|MAN|A netwwork connecting a city or large campus area|Telecom|
|WAN|A network covering large geographical areas|Multinational firms|
|DNS|Translates a domain name into an IP address|Public and Private DNS services|
|Router|Connects networks and forwards data between them|WIFI router|
|Protocol|A set of rules devices to follow to communicate|HTTP, HTTPS, SMTP|
|Packet Switching|Data is divided into packets that travel across a network|Sending a text message, the message is broken down into several data packets and sent|
|Client-Server|A client requests a service and a server provides it|Requesting a github server|

1) Opening a browser - Client starts the request
2) The requests are sent according to the protocol
2) DNS convers the domain name into IP address
3) Data packets are sent as requests to the IP address converted by DNS through the router
4) The server gets the data packets
5) Server gives a reponse based on the request made
6) The response arrives at our computer and the page loads up.
